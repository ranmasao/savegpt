# SaveGPT

Chrome extension to save ChatGPT conversations as Markdown.

1. Open `chrome://extensions` and enable Developer mode.
2. Click **Load unpacked** and select this directory.
3. Open a saved conversation on `chatgpt.com` and click **Save as Markdown** in the extension.

See [documentation](DOCUMENTATION.md) for limitations, output format, and development. Licensed under [MIT](LICENSE).
